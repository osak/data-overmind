# このディレクトリについて

開発時に使うソフトウェアデザインに関連するドキュメントを集めるディレクトリ。

## ファイルの規約

このディレクトリの直下には、以下のどちらかのルールに従ってファイルを配置する。

- `yyyy-mm-dd_<topic>.md` というMarkdownファイルを作る。
- `yyyy-mm-dd_<topic>/` というディレクトリを作り、その下に自由なファイル名で関連ファイル群を配置する。

生成するドキュメントには、必ず冒頭に最終更新日時を含める。

## ファイルの内容とstaleness

このディレクトリにあるファイルは、すべてその日付時点での調査結果や決定した方針のsnapshotであるとみなす。
現在のプロジェクトの状態と地続きである可能性は高いが、最新の状態とは必ずしもsyncしていない。最終更新日時はあくまでも最後にファイルを更新した日時であり、その日時時点での最新情報を正確に反映している保証はない。

## ファイルの読者

このディレクトリに含まれるファイルは、AIによって消費される前提の、詳細で文章構造にあまり注意を払っていないものと、人間によって消費されるものがある。
ファイルを作る際には、そのファイルの読者がどちらであるかを意識して作成すること。特に、人間はAI向けに書かれたドキュメントを読むことに多大な苦痛を覚える。
